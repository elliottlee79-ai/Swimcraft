魚の切り抜き方

自分の魚の画像で釣り場に放流すると、Swimcraftは釣果カードや記録ボードでそれを3D表示します。そのためには、背景に何もない、魚だけの画像が必要です。このページでは、スマートフォンに任せる場合も手作業でやる場合も、その方法を紹介します。

>

ゲームに必要なもの

  • 魚だけ。マット、草、玉網、手、人は不可です。すべての釣り場は公開前に確認され、これらが写っている画像は承認されません。
  • PNGで保存。PNGは背景を透明にできます。JPGはできないので、ゲームはJPGを受け付けません。WebP画像も使えます。
  • 魚の全身を真横から。ヒレや尾が端で切れていないように。
  • ある程度の大きさ。魚の長さが少なくとも1,000ピクセルになるようにしましょう。ゲームはそれより大きな画像を長辺1,024ピクセルに縮小するので、大きめの画像でも問題ありません。
  • 自分の写真。アップロード時に確認を求められます。

写真から位置情報を事前に削除する必要はありません。ゲームが画像を保存するときにその情報を取り除きます。

まずは適切な写真から

良い切り抜きは良い写真から。岸での数秒が、あとの手間を大きく減らしてくれます。

  • 魚をマットの上に平らに寝かせ、真上から、真横の姿を撮りましょう。
  • 安全にできるなら、撮影のときは魚から手を離しましょう。魚体にかかった指は、きれいに切り抜くのがいちばん難しい部分です。
  • 魚の全身を入れましょう。周り全体に少しマットが見えるくらいに。
  • 無地で、魚と色の違う背景を選びましょう。緑色のテンチの下に草があるより、銀色の魚の下に暗い色のマットがあるほうが、どんなツールでもずっと簡単です。

魚をカメラに向かって掲げる定番の記念写真は、いちばん使いにくい写真です。魚が遠近で縮んで形が崩れ、釣り人の手が魚体にかかっています。

手早い方法：ツールに任せる

今ではほとんどのスマートフォンやパソコンで、魚を背景から切り抜けます。こうしたツールは手早いですが、あくまで推測です。親指、網の端、マットの切れ端などが残っていることがよくあるので、必ず結果をよく確認しましょう。あとから下で紹介する方法で手作業で整えられます。

iPhone

  1. 写真で写真を開き、共有をタップしてから"ファイル"に保存をタップします。
  2. ファイルアプリを開いて写真を探します。写真は開かないでください。
  3. 写真を長押しして、クイックアクション、背景を削除の順にタップします。
  4. 被写体だけの新しいPNGが同じフォルダに作られます。それがアップロードするファイルです。

写真アプリの中で魚を長押ししても切り抜けますが、作られるコピーで背景の透明さが保たれるとは限りません。ファイルアプリ経由なら、きちんとしたPNGが保存されます。

Samsung Galaxy

  1. ギャラリーアプリで写真を開きます。
  2. 魚の周りに輪郭が表示されるまで長押しして、指を離します。
  3. 画像として保存をタップします。切り抜きがPNGとしてギャラリーに保存されます。

ほかのAndroidスマートフォンでも、写真アプリに同様の機能があるかもしれません。ない場合は、下のパソコン向けの方法を使うか、手作業で行いましょう。

Windows 11：ペイント

  1. 写真を右クリックして、プログラムから開く、ペイントの順に選びます。
  2. ツールバーの背景の削除をクリックします。
  3. 拡大して輪郭を確認しましょう。残ったものは、下で説明するように消しゴムで整えます。
  4. ファイル、名前を付けて保存、PNG画像の順に選び、新しい名前を付けます。

背景の削除が見当たらない場合は、Microsoft Storeからペイントを更新してください。Windows 10のペイントでは透明な画像はまったく作れないので、代わりに下にある無料の画像編集ソフトを使いましょう。

どのパソコンでも：無料のウェブサイト

Adobe Expressなどの無料の背景削除サイトでは、写真をアップロードして被写体のPNGをダウンロードできます。選ぶ前に、無料でダウンロードできるサイズを確認しましょう。無料では小さなプレビュー（幅600ピクセル程度のことが多い）しかもらえないサイトもあり、それだと釣果カードでぼやけて見えます。

丁寧な方法：手作業で

ヒレの筋まで一本一本正確にしたい場合や、写真をAIツールに渡したくない場合は、自分で魚を切り抜くのも簡単です。10〜15分ほどかかり、仕上がりはあなたの根気次第です。

Windows 11のペイントで

最近のバージョンのペイントが必要です。確認するには、写真の隅を消しゴムでこすってみてください。グレーと白の市松模様が見えれば準備OKです。消した部分が白くなる場合は古いペイントで、透明な画像は保存できません。代わりに下の無料の画像編集ソフトを使いましょう。

  1. 写真を右クリックして、プログラムから開く、ペイントの順に選びます。
  2. まずはトリミングしましょう。選択を選び、魚の周りに少し余白を残して四角形をドラッグし、トリミングをクリックします。消す部分がずっと少なくなります。
  3. 消しゴムを選んでサイズを大きくします。魚から十分離れたところの背景を消しましょう。
  4. Ctrlとマウスホイールで拡大し、魚に近づくにつれて消しゴムのサイズを小さくしていきます。
  5. 輪郭に沿ってゆっくり進めましょう。ヒレや尾は短いストロークで消し、ヒレの先は削らずに残しておきます。
  6. 間違えたら、Ctrl + Zで直前のストロークを取り消せます。
  7. お好みで：魚が右を向いている場合は、回転、左右反転の順に選んで、ゲーム内の魚と同じように頭を左向きにしましょう。
  8. ファイル、名前を付けて保存、PNG画像の順に選びます。JPEGは選ばないでください。消した部分がすべて白で埋められてしまいます。

数分ごとに新しい名前でコピーを保存しましょう。あとでストロークを大きく失敗しても、最初からやり直さずに最後の良いコピーに戻れます。

無料の画像編集ソフトで

とても細かい輪郭には、本格的な画像編集ソフトを使えば、ほかの部分をすべて消す代わりに魚の周りに線を引けます。おすすめの無料ソフトは3つ。Windows用のPaint.NET、ウェブブラウザで動くPhotopea、どのパソコンでも使えるGIMPです。ボタンは少しずつ違いますが、考え方は3つとも同じです：

  1. 写真を開きます。
  2. なげなわツールで、魚の周りを一周丁寧になぞります。拡大すると楽です。
  3. 選択範囲を反転して、魚以外のすべてを選択します。
  4. Deleteを押します。背景が市松模様になるはずです。
  5. 画像をPNGとして書き出すか保存します。

削除しても背景が市松模様ではなく白くなる場合は、画像のレイヤーがロックされています。レイヤーパネルでロックを解除するか、GIMPならレイヤーにアルファチャンネルを追加してから、もう一度削除しましょう。

アップロードする前に確認

  1. PNGをウェブブラウザで開くか、暗い背景の上に置いてみましょう。
  2. 輪郭を一周見て、白いふち、親指、網やマットの切れ端がないか確認します。
  3. ヒレや尾が切れていないことを確認します。

それから釣り場クリエイターで放流に進み、魚の画像の下にある切り抜き画像をアップロードを使います。放流の1行全体に1枚の画像を設定することも、特定の重さごとに別の画像を追加することもできます。プレビューにマウスを乗せると3Dで表示されます。

ゲームに画像を受け付けてもらえない場合

ゲームはアップロード時にすべての画像をチェックします。受け付けられない場合は、メッセージで理由が表示されます：

「JPG画像は背景を透明にできません。」
ファイルがJPGです。切り抜き画像をもう一度開いて、PNGで保存してください。
「この画像にはまだ背景があります。」
画像の端が透明になっていないので、背景がまだ残っています。いちばん多い原因は古いペイントで保存したことで、消した部分が白くなってしまいます。もう一度背景を削除して、PNGで保存してください。
「切り抜いた魚ではなく、透明なシートに載せた写真のようです。」
四角い写真全体が、魚の周りにマットが残ったまま透明な背景の上に置かれています。魚そのものの周りを切り抜いてください。
「その画像を読み込めませんでした。」
ファイルが壊れているか、ゲームが開けない形式の可能性があります。ペイントや画像編集ソフトで開いて、PNGでもう一度保存してください。
